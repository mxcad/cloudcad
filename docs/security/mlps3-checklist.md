## 8.1.1 安全物理环境（10 个控制点）

> **云上责任分担说明**：CloudCAD 生产环境为西部数码云服务器（IaaS）。机房选址、门禁、消防、供电等物理安全由云服务商承担并以其自身等保资质兜底。本项目侧义务是：
> ① 采购时核验云商**等保三级及以上备案/测评证明**并留档（对应 8.1.9 服务供应商选择）；
> ② 在合同/SLA 中固化物理安全责任条款；
> ③ 送测时向测评机构提交云商资质证明作为间接证据。
> 因此下表逐条标"不适用"，但①②③尚未执行前，本类实质处于"**不适用但依赖项未闭环**"状态。

以下控制点以「补偿性控制组合」申辩通过测评尺度，而非逐字满足条款原文。叙事主轴：**承载企业核心设计资产与服务连续性**（定级报告论证主轴），零成本姿态下以「端口收口 + 应用层纵深防御 + 告警闭环 + 制度文书」组合替代商业安全产品。

| 控制点 | 未满足的子项 | 补偿控制组合 |
|---|---|---|
| 8.1.2.2/8.1.4.7 传输保密/完整性（内部段） | 内部链路无 TLS | 可信内网隔离（#408 决策）：端口收口 127.0.0.1 + 共享密钥鉴权 + REDIS_PASSWORD 必填；多机拆分时自动失效重开条款（docs/compliance/internal-network-isolation.md） |
| 8.1.2.3/8.1.3.6/8.1.4.6 可信验证 | 不采用 TCM/TPM | 行业普遍现状（三级测评低风险项），以镜像来源可信（内容寻址 Release 资产）+ 依赖漏洞门禁（#423）申辩 |
| 8.1.3.3 边界入侵防范 | 无 WAF/IDS/抗 DDoS 产品 | fail2ban SSH 封禁 + 登录失败突增 P1 告警（Prometheus 规则 + AlertService）+ 端口收口（#418）；云商 DDoS 基础能力待 #414 确认 |
| 8.1.3.4 垃圾邮件子项 | 系统不含邮件网关 | 邮件仅出站（SMTP 发告警/验证码），无入站网关，子项不适用化申辩 |
| 8.1.4.2(f) 客体细粒度授权 | 无行级/表级 DB 授权 | 应用层 RBAC + 项目级数据隔离 + 三权分立（数据访问全部经应用层鉴权，无直连 DB 通道） |
| 8.1.4.8 数据保密性（传输段） | 公网无 TLS | 待公网 TLS 工程闭环（P0）；PII 存储侧已字段级加密（#417），wechatId/nickname/IP 列入风险接受清单（访问控制 + 审计覆盖） |
| 8.1.4.9(c) 热冗余 | 单机无热冗余 | 每日备份 + 异地推送 + 月度恢复演练（RPO≤1h/RTO≤4h 制度）；架构升级超本图范围 |
| 8.1.5.1 堡垒机 | 无会话录制 | 「轻量三件套」：端口收口 + fail2ban + CLI 运维留痕（#418）+ SSH 仅密钥 |
| 8.1.4.4/8.1.10.5 镜像漏洞扫描 | 无 trivy 镜像扫描 | 依赖层 audit-ci 门禁 + 镜像来源内容寻址（#423/#445）；镜像扫描走补偿申辩 |
| 8.1.10.9 密码管理 | 无国密/密评 | 标准算法（bcrypt/AES-256-GCM/HMAC-SHA256/JWT）业界通行；密评口径待公司咨询测评机构 |
| 8.1.4.10 剩余信息保护 | 内存/磁盘块级清零未管理 | 账户注销 13 类数据物理删除 + 敏感数据删除操作记录留档（#424）；bcrypt 盐值随机属行业等效实践 |

> 使用方式：送测材料中按控制点引用上表对应行，附证据链接（各控制点行「证据/差距说明」列的提交哈希/文件路径/测试）。

## 送测前置动作（代码已交付、须显式开启/部署机执行）

1. **开启 MFA 总闸**：运行时配置 `mfaEnforceEnabled=true`（管理员 TOTP 强制，#415）；
2. **开启口令定期更换总闸**：`PASSWORD_POLICY_CHANGE_ENFORCE_ENABLED=true`（ADMIN 180 天强改，#416）——两项默认关闭，测评前开启并留配置截图；
3. **公网 TLS 证书落位**：代码侧已交付（#408），签发证书并落位 `./data/certs/`（fullchain.pem/privkey.pem），entrypoint 自动切 TLS 模板；部署机实机验证 443 握手 + 80→443 跳转（P0，阻塞项）；
4. **PII 生产回填 + 明文列下线**：#426 运维阶段（部署机执行 backfill 三重校验 → 下线脚本三阶段）；
5. **部署机演练清单**（见下节）。
