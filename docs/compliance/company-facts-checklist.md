# 公司事实收集总单（等保三级）

> **用途**：等保三级工程（#401 地图）中所有需要公司提供的**事实字段**的唯一收集出口。制度文档中的 `【待公司：CF-xx】` 标记与本表 CF 编号一一对应；勾选后把事实值填入「事实值」列，并同步回填对应制度文档。
> **用法**：本表可直接打印交公司行政逐项勾选；「事实值」列填写后，按「对应文档/位置」列回填，制度文件即具备签发条件。
> **图例**：☐ 未勾选　☑ 已勾选（事实值已填）。「对应文档」列给出该事实的落点（相对 `docs/` 路径）。

## 三、回填与生效流程

1. 公司行政逐项勾选，「事实值」列填写事实（人员项附姓名/账号/联系方式）；
2. 按「对应文档/位置」列把事实值回填制度文档，替换对应 `【待公司：CF-xx】` 标记（同一 CF 编号在多处出现时全部替换）；
3. 各制度文件文末审批栏签署（CF-03），发文表补文号/生效日期（CF-02/CF-04）；
4. 更新 [制度索引签发状态表](../ops/README.md) 为 ☑ 已签发，并同步 [等保自查清单](../security/mlps3-checklist.md) 8.1.6.2–8.1.6.4 状态；
5. 备案材料节（F-01–F-10）完成后，按 [备案表填写要点清单](mlps3-filing-form-points.md) 提交备案。

> **唯一出口约定**：制度文档中新增的公司事实字段，必须先在本表登记编号再引用，禁止文档内出现无编号的 `【待公司】` 裸标记。
