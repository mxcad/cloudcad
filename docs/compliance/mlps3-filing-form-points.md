# 《信息系统安全等级保护备案表》填写要点清单

| 项 | 内容 |
|---|---|
| 文档性质 | **填写要点核对清单**（非表格本体——官方表格以当地公安机关网安部门提供的最新版为准，多数省份经全国互联网安全管理服务平台线上填报） |
| 适用对象 | 梦想网页CAD实时协同平台（CloudCAD 在线版），拟定等级第三级 |
| 依据 | 《信息安全等级保护管理办法》（公通字〔2007〕43 号）第十五条、第十六条；GB/T 22240-2020 |
| 配套材料 | [定级报告草案](mlps3-grading-report-draft.md)；自查清单 [mlps3-checklist](../security/mlps3-checklist.md) |

> **图例**：**【待公司填写】** = 需要公司行政提供的事实字段；【口径】 = 可直接套用的建议写法；（要点）= 避免退回的注意事项。

## 提交前素材收集总单

公司行政需要一次性备齐的事实与证照：

- [ ] 营业执照副本扫描件（统一社会信用代码、法人、住所信息以其为准）
- [ ] 运营单位全称及简称定稿（备案主体必须与营业执照一致）
- [ ] 是否有行业主管部门及其全称（无则按当地口径确认填报方式）
- [ ] 法定代表人姓名 + 办公电话；经办联络员姓名 + 手机号 + 电子邮箱
- [ ] 生产域名清单 + ICP 备案号（**域名须已完成 ICP 备案且备案主体一致**）
- [ ] 云主机公网 IP 地址段、云服务商名称、机房所在省市
- [ ] 系统正式上线运行日期
- [ ] 当前注册用户数 / 服务范围表述
- [ ] 专家评审会议纪要 + 专家名单与签字表（不少于当地要求的评审人数，通常为 3 名以上具有专业技术职称人员）
- [ ] 单位公章（表四需加盖）

## 常见退回原因对照自查

1. 系统名称在备案表、定级报告、上线网页（页脚/关于页）三处不一致；
2. 域名未做 ICP 备案或 ICP 主体 ≠ 备案主体；
3. 缺专家评审签字表或专家人数不足；
4. 定级报告论证太空泛（只有结论没有要素分析）——本票配套草案第二章即为此而写，勿删减；
5. IP 清单与实际解析不符（DNS 记录变更未同步）；
6. 表四落款日期逻辑链错误（早于评审/晚于受理）。

## 与本仓现状的事实钩子

- 生产环境公网 TLS 尚未部署（自查清单 P0 #1）：送审前上线 HTTPS 并将最终域名/IP 回填表二——裸 HTTP 入口写入备案材料会被问询。
- 目前无任何涉密业务承诺文书：定级报告中"国家安全不涉及"的前提依赖业务侧书面确认，办理前先取得。
- 备案周期较长且是测评前置条件：建议公司尽快启动本清单的素材收集，与本仓工程整改票并行推进。
