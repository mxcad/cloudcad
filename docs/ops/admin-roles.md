## 1. 三权分立原则

系统权限按"**审批、执行、审计**"相互分离：

- **系统管理员（SYSTEM_ADMIN）**：日常系统运维，不持有审计清理权；
- **审计管理员（AUDIT_ADMIN）**：唯一持有审计日志清理权的角色（代码层强制，见 `audit-log.controller.ts` 的 `@RequirePermissions([AUDIT_ADMIN])`），负责日志审查与归档；
- **安全管理员（SECURITY_ADMIN / 安全负责人）**：负责账号授权审批、IP 黑白名单策略、安全事件处置决策。

三权不得由同一人兼任；确因规模限制需兼岗的，须在【待公司：CF-06 上级主管】书面批准下注明并加强抽查频率。

## 4. 授权与回收流程

1. 授权申请：【待公司：CF-07 申请载体】，注明角色、期限、理由；
2. 审批：SECURITY_ADMIN 或【待公司：CF-06 上级主管】批准；
3. 开通：由 SYSTEM_ADMIN 在系统内创建账号并授予对应角色；
4. 定期复核：每季度核对本表与实际在岗人员一致，离岗当日回收账号（频率与时效为制度默认值，公司确认项见总单 CF-20）；
5. 全部授权与回收操作均可在审计日志中回溯（`ROLE_UPDATE` / `PERMISSION_GRANT/REVOKE` / `USER_DEACTIVATE`）。
