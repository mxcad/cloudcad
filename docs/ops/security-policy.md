# 网络安全工作总体方针

> 等保对照：8.1.6.1（安全策略：制定网络安全工作总体方针与策略，阐明总体目标、范围、原则和安全框架）。
> 本文件为安全管理体系**顶层方针**，是各管理制度与操作规程的纲领；具体执行以本文第 4 节所列制度文件为准。
> 制度体系总览与签发状态见 [制度索引](README.md)；公司事实字段（签发主体、日期等）统一在 [公司事实收集总单](../compliance/company-facts-checklist.md) 勾选回填。

## 1. 总体目标

保障「梦想网页CAD实时协同平台」（CloudCAD 在线版，拟定等保第三级）的**机密性、完整性、可用性**，实现：

- 用户数据（图纸文件、账号信息、审计日志）不被未授权访问、泄露或篡改；
- 平台持续可用，故障恢复满足 RPO ≤ 1 小时、RTO ≤ 4 小时（见 [备份与恢复制度](backup-restore-policy.md)）；
- 安全事件可发现、可追溯、可处置，处置过程全程留痕；
- 满足 GB/T 22239-2019 第三级要求，支撑备案、测评与持续合规。

## 2. 适用范围

- **对象**：本平台全部生产环境（应用服务、数据库、文件存储、协同服务、运维监控栈）及其承载主机；
- **人员**：全体员工，其中系统管理员、审计管理员、安全管理员（三员，见 [管理员角色分工表](admin-roles.md)）负有直接安全职责；
- **活动**：系统建设、上线、日常运维、变更、备份恢复、事件处置、人员授权与离岗的全部环节。

## 3. 基本原则

1. **最小授权**：账号与权限按岗位职责授予，三权分立（审批、执行、审计分离），离岗当日回收；
2. **默认拒绝**：未显式允许的访问、端口、来源一律拒绝；
3. **全程留痕**：管理员操作、授权变更、日志查阅与清理自动写入审计日志，原始日志不得删改；
4. **纵深防御**：边界防护、身份鉴别、访问控制、恶意代码防范、备份恢复多层设防，不依赖单一控制；
5. **持续改进**：漏洞限期修复，制度定期评审修订，演练验证有效性。

## 5. 制定、发布与评审（8.1.6.3 / 8.1.6.4）

- **责任**：安全管理员（SECURITY_ADMIN）牵头制度制定与修订，系统管理员协助技术内容，上级主管批准；
- **发布**：制度以本仓库 `docs/ops/` 为唯一版本源（git 版本控制），签发状态跟踪于 [制度索引](README.md)；
- **评审**：每年度至少一次评审制度合理性与适用性（结合漏洞台账、事件事后报告、测评整改项），修订后升版本号并记录；
- **备案联动**：制度签发与三员任命是等保备案、测评的前置材料，进度以 [公司事实收集总单](../compliance/company-facts-checklist.md) 为准。
