## 1. 日志范围

| 日志类型                      | 存储位置                                                                                           | 系统默认留存                                         | 部署方留存要求                      |
| ----------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------- | ----------------------------------- |
| 审计日志（audit_logs 表）     | PostgreSQL                                                                                         | 默认 183 天（`AUDIT_LOG_RETENTION_DAYS` 可调，#322） | ≥183 天；涉等保场景建议 ≥6 个月    |
| 应用运行日志（NestJS Logger） | `data/logs/<service>/app-*.log`（promtail 采集进 Loki，`log_type=app`）                            | 90 天（Loki `retention_stream` 默认）               | ≥90 天；需更长则调 `docker/monitoring/loki/local-config.yaml` |
| Nginx/网关访问日志            | 本部署 Nginx `access_log` 关闭；应用层访问日志落 `data/logs/<service>/access-*.log`（promtail 采集进 Loki，`log_type=access`） | 180 天（Loki `retention_stream` 默认）              | ≥180 天；需更长则调 `docker/monitoring/loki/local-config.yaml` |
| 审计归档文件                  | `AUDIT_ARCHIVE_PATH`（默认 `data/archives/audit-logs`，系统按月自动归档 CSV + SHA-256 清单，#322） | 随归档产物长期留存                                   | 【待公司：CF-15 异地备份目的地】   |

（留存期与归档策略为制度默认值，公司确认项见总单 CF-17）

## 2. 归档与备份

- 系统自动归档（#322 已实现）：开启 `AUDIT_ARCHIVE_ENABLED=true` 后，超期记录删除前按月分片导出 CSV + SHA-256 校验清单（fail-closed，归档成功才删库）；运维只需按制度将 `data/archives/audit-logs/` 同步至【待公司：CF-15 异地备份目的地】；
- 历史归档检索：`pnpm audit:archive-query -- --month YYYY-MM [--userId/--action/--keyword]`（先校验 SHA-256 清单再输出，#324）；
- 每月由审计管理员（AUDIT_ADMIN，在岗人员见总单 CF-05）复核归档完整性；
- 归档介质校验：清单可用 `sha256sum -c YYYY-MM.sha256` 校验；
- 清理操作约束：手动清理仅限审计管理员执行（系统已做三权分立，仅 `AUDIT_ADMIN` 可调用清理接口）；清理前必须确认对应时段已完成归档。

## 3. 查阅权限与审批

| 操作             | 允许角色                       | 审批流程                          |
| ---------------- | ------------------------------ | --------------------------------- |
| 页面查询审计日志 | `AUDIT_ADMIN` / `SYSTEM_ADMIN` | 无需逐次审批，操作本身留痕        |
| 导出审计日志     | 同上（导出动作自动记审计）     | 批量/全量导出需安全负责人审批     |
| 数据库直查审计表 | 仅 DBA                         | 工单 + 安全负责人批准            |

**脱敏要求**：对外提供或跨部门共享时，email、IP 地址、手机号等个人信息字段必须脱敏（如 `192.168.*.*`、`a***@example.com`）；口令类字段系统本就不落审计，无需额外处理。

## 4. 定期审查

- 频率：每周例行、每月专项（公司确认项见总单 CF-20）；
- 例行审查项：
  1. 失败登录与 `ADMIN_LOGIN` 失败记录是否异常集中；
  2. 权限授予/回收（`PERMISSION_GRANT/REVOKE`）、角色变更是否有非计划操作；
  3. IP 黑白名单变更是否均有对应工单；
  4. 审计清理任务是否正常执行、失败告警是否处理。
- 审查记录：【待公司：CF-11 工单/登记表载体】。

服务器与数据库统一使用【待公司：CF-12 NTP 服务器地址】校时，保证审计时间戳可信（时区 Asia/Shanghai）。
