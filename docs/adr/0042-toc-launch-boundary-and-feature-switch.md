# ADR-0042: C 端（TOC）首版开放边界与功能开关灰度
**Status**: accepted

CloudCAD 以同一代码库服务 TOB（私有化）与 TOC（公有云）两类客户。C 端首版上线时，对公众暴露的功能范围必须有明确边界：**首版开放「CAD 编辑/预览、上传保存、版本历史、图纸分享、VIP 付费、个人空间」**；**重资源功能（实时协同、批量下载）默认关闭，通过运行时开关灰度放量**；桌面 EXE 客户端是独立项目，不在本项目 C 端范围内（后端设备码接口保留复用）。

## 上下文

- 协作已有 `collaborationEnabled` 运行时开关（默认 `false`，`isPublic: true`）；批量下载（`batch-download/`）原本**无任何开关或权限门槛**，一次请求可打包整个目录 ZIP，C 端开放后易被脚本批量爬取图纸、打爆后端 IO——故新增 `batchDownloadEnabled` 开关（默认 `false`），入口处守卫。
- 免费层（VIP0）配额沿用代码默认值（个人存储 50MB / 单项目 100MB / 每日转换 10 次 / 项目数 5），全部可在管理后台动态调整，无需开发。
- 注册路径零开发：微信登录（`wechatEnabled` / `wechatAutoRegister`）、邮箱注册、短信验证码均为既有运行时配置。
- 产品体系只有 VIP0（免费）+ 限时 VIP 等级，**不存在"永久会员"商品**；代码中 `expiresAt: null && tierLevel > 0` 仅是历史数据兼容兜底状态，不得作为新功能开发。

## 决策

1. **开放范围**：编辑器（含预览/转换）、上传保存、版本历史、分享、VIP 购买与会员中心、个人空间对 C 端开放；桌面 EXE 由独立项目交付。
2. **功能开关灰度**：实时协同与批量下载默认关闭，需要时在运行时配置中心开启（可逆、免发版）。未来新增面向 C 端的重资源功能时，默认遵循同一模式：先有开关，再开放。
3. **部署形态**：standalone 模式（backend + storage-service + conversion-service）起步，三进程部署在同一台服务器上；遇到瓶颈后按「同机调优并发 → 多实例（需先验证任务分发）→ 分机/云 FaaS」顺序扩容（扩容路径见 ADR-0016）。
4. **上线 checklist（非代码）**：正式域名切换（当前 demo.mxdraw3d.com）→ 新域名备案、微信开放平台回调白名单、微信支付 notify_url、HTTPS 证书；隐私政策/用户协议页面纳入首版前端。

## Consequences

- C 端公众流量下的资源滥用风险被闸门兜住（批量下载一键可关）；协作可灰度观察后再放量。
- 批量下载入口需接入 `batchDownloadEnabled` 守卫（实现任务），前端对应隐藏/禁用入口。
- 换正式域名是纯配置切换 + 外部平台清单，代码无硬编码部署域名（已核查）。
