# CloudCAD 私有化部署说明（Windows）

## 〇、系统要求（必读）

- **操作系统**：Windows Server 2016 或更高版本（2019 / 2022 / 2025 同样支持）。
  - **不支持** Windows Server 2008 R2 与 2012 R2：随包的 Node.js 20 与 PostgreSQL 15 官方均不支持这两个版本，属硬性限制，无法通过降级依赖解决。
- **架构**：仅支持 **64 位（x64）** 系统，无 32 位版本（含 32 位 Server Core）。
- **部署路径**：必须为纯英文路径，详见下方「首次部署」。
- 无需安装任何前置运行库，全部依赖随包自带。

## 一、首次部署

1. 将部署包解压到**纯英文路径**（例如 `D:\CloudCAD`，中文路径会导致数据库与 CAD 引擎无法工作）。
2. 双击根目录 `start.bat` ——首次运行会自动完成：
   - 初始化配置与依赖（离线）
   - 设置管理员/数据库/Redis 密码（按提示输入或自动生成）
   - 数据库迁移、服务启动、图纸版本检查与验证
3. 完成后浏览器访问 `http://<本机IP>:8000` 使用系统。

## 二、日常运维入口

| 入口 | 用途 |
|------|------|
| `start.bat` | 一键启动（部署包内自动执行部署流程） |
| `stop.bat` | 停止全部服务 |
| `runtime/cloudcad.bat` | 交互式运维菜单（启动/状态/日志/备份等） |
| **运维中心网页** `http://<本机IP>:3002` | 网页版运维：服务启停、部署升级、迁移、日志查看与打包、TOTP 解绑 |

### 运维中心（推荐）

浏览器打开 `http://<本机IP>:3002`，使用**管理员密码**（首次部署时设置的
`INITIAL_ADMIN_PASSWORD`）登录。「运维中心」标签页提供：

- 服务启停与部署/升级（自动完成版本检查、数据库迁移、版本验证）
- 日志中心：查看全部日志位置、在线查看、**一键打包下载**（发给技术支持）
- 管理员 TOTP 解绑（管理员丢失验证器时的恢复通道）

> 运维密码与产品管理员密码同源（初始相同），可在登录后的「修改密码」中独立修改。

## 三、日志与备份位置

- 全部服务日志：`data/logs/` 与 `data/pm2/logs/`，部署过程日志在 `data/logs/deploy/`
- 一键打包：运维中心网页「打包全部日志」，或运维菜单 [日志中心] → 打包
  （产物在 `data/log-bundles/logs-<时间戳>.zip`）
- 数据库备份：`data/backups/`

## 四、升级

1. 获取增量升级包，解压覆盖到现有部署根目录。
2. 双击 `start.bat`——自动完成依赖增量安装、数据库迁移与服务重启。
3. 也可在运维中心网页点「开始部署」完成同样流程。

## 五、常见问题

- **端口占用**：默认端口 8000（前端）、3001（后端）、3002（运维中心/配置中心）、5432（PostgreSQL）、6379（Redis）。
- **服务起不来**：先看运维中心「服务管理」或 `runtime/cloudcad.bat` → [查看服务状态]；日志用「日志中心」打包排查。
- **改名/移动/删除部署目录**：前台模式关闭终端窗口（或部署失败）后，请等待约 15~60 秒让全部服务停止完成，再改名/移动/删除部署目录；过早改名会提示「目录正在使用，无法重命名」。若目录已被改名/移动，直接双击 `start.bat` 即可——系统会自动检测失效的依赖链接并重建，无需手动处理。
- **忘记管理员密码**：到服务器运行 `runtime/cloudcad.bat admin:reset-password`，
  或双击 `runtime/cloudcad.bat` 进菜单选 [重置管理员密码]。新密码由系统生成并在
  终端只显示一次，请当场记录；同时撤销该管理员全部刷新令牌，操作留审计。
  若 TOTP 验证器也丢了，加参数 `--also-unbind-totp`。
- **管理员忘了 TOTP 验证器**：运行 `runtime/cloudcad.bat mfa:totp-unbind <用户名>`，
  解绑后该管理员下次登录重新绑定验证器即可。
- **忘记 / 轮换数据库密码**：运行 `runtime/cloudcad.bat db:reset-password`，
  或双击 `runtime/cloudcad.bat` 进菜单选 [重置数据库密码]。新密码由系统生成并在
  终端只显示一次，请当场记录。命令会用新密码回连 PostgreSQL 验证，验证通过才
  更新 `.env`（`DB_PASSWORD` 与 `DATABASE_URL` 成对写）并重启后端；验证失败会
  回滚为旧密码。不索取旧密码。运维中心 3002 的「修改数据库密码」是同一通道。
- **忘记 / 轮换 Redis 密码**：运行 `runtime/cloudcad.bat redis:reset-password`，
  或双击 `runtime/cloudcad.bat` 进菜单选 [重置 Redis 密码]。改密不停机，成功后
  按 Redis → 后端 → 转换服务顺序重启（只重启实际存在的服务）。同样先用新密码
  AUTH 验证通过才写 `.env`。运维中心 3002 的「修改 Redis 密码」是同一通道。
- **在系统前面自配了反向代理（nginx 等）**：系统有通知、会员状态等实时推送
  通道（SSE 长连接）。若代理配置不当，实时事件会延迟甚至丢失，请确认两点：
  1. 关闭代理响应缓冲：`proxy_buffering off;`（服务端已发送
     `X-Accel-Buffering: no` 响应头，nginx 默认会遵循该头自动关缓冲；
     仅当配置里显式写了 `proxy_buffering on` 时才需要改）。
  2. 给长连接留足读超时，例如 `proxy_read_timeout 1h;`（nginx 默认 60 秒
     会周期性切断长连接；客户端会自动重连，但事件推送会短暂中断）。
  nginx 示例：
  ```
  location / {
      proxy_pass http://127.0.0.1:8000;
      proxy_http_version 1.1;
      proxy_set_header Connection "";
      proxy_buffering off;
      proxy_read_timeout 1h;
  }
  ```
